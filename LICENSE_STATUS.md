That data license does not automatically license project code or certify every upstream right.

Existing approvals established the original curated bundle's inclusion in the PRIVATE repository and hosted demonstration. No explicit approval specifically clearing the three data files plus QA overlay for a PUBLIC GitHub repository could be established from the retained release manifests (which still mark the inventory as proposed). Therefore the source-showcase package omits both data and QA overlay. It publishes runnable presentation/analytical code with a safe unavailable-data state and a reproducibility limitation, not a fake dataset. The static site includes only previously requested public statistical narratives and original static assets. Future data publication requires a separately reviewed allowlist, original sizes/hashes, attribution and explicit distribution approval; never regenerate the approved release.
